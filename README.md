## 1. Overview
This repository contains the source code and demo data used in our study. The scripts cover the entire analysis pipeline, from pupil data preprocessing to fPCA and Markov Chain analysis.

## 2. System Requirements
*   **Python Version:** 3.12
*   **Dependencies:** The code requires standard data analysis libraries. You can install them via pip:
    ```bash
    pip install numpy pandas scipy matplotlib scikit-learn openpyxl
    ```

## 3. File Structure & Usage
The scripts are numbered to indicate the execution order. Please run them sequentially:

*   `01_pupil_preprocessing.py`: Preprocesses raw pupil data (blink interpolation, normalization).
*   `02_jTTC_power_law_fitting.py`: Fits the power-law models.
*   `03_temporal_dynamic_analysis.py`: Analyzes temporal dynamics.
*   `04_fPCA_analysis.py`: Performs Functional Principal Component Analysis.
*   `05_markov_chain.py`: Conducts Markov Chain analysis.

## 4. Note on Demo Data & Results
**Important:** 
Due to privacy and copyright considerations, the full dataset is not included. 
*   **Input:** The scripts use `demo_raw_data_10subs.jsonl` and `demo_data.xlsx`, which contains raw data from **random 10 subjects** only.
*   **Output:** Consequently, the statistical results (e.g., p-values, coefficients) generated by these scripts **will differ** from the full-sample results reported in the manuscript. The purpose of this repository is to demonstrate the analysis pipeline and code reproducibility.

**Usage Note:** Please unzip `demo_raw_data_10subs.zip` after downloading and place the extracted file in the same directory as the code before running the analysis.
